Privacy policy

Last updated: September 2026

Short version

firm-bot runs entirely on your own hardware. Your documents, questions, and answers do not leave your machine. We collect no telemetry, run no analytics, and load no third-party tracking scripts. The only network calls firm-bot makes are the ones you explicitly configure (for example, pulling a model from Ollama on first boot, or installing dependencies with pip).

Local-first architecture

firm-bot is designed so that operating the system does not require contacting any third party. The retrieval pipeline (chunking, embedding, vector search, generation) runs locally using Ollama, sentence-transformers, and Chroma. There is no embedded analytics SDK, no usage beacon, no remote logging, and no "phone-home" check-in. If you want firm-bot to be reachable from another device on your network, you opt in by binding to a non-loopback address; that traffic never leaves your LAN.

What the audit log records

firm-bot writes an append-only JSONL audit log per firm so that your compliance or security team can review who asked what, when, and against which document version. To make the log SIEM-friendly without leaking privileged content, only metadata is recorded:

  • Timestamp (UTC) and request ID
  • SHA-256 hash of the question text — never the question itself
  • SHA-256 hash of the answer text — never the answer itself
  • Citation count, retrieval latency, model name and version
  • Client IP, user-agent, and API key identifier (when auth is enabled)
  • Guard verdict (grounded / ungrounded / refused) from the LLM-as-judge

Question and answer bodies are never stored in the audit log. This is a deliberate choice: the audit log proves that a query happened and what model was involved, but cannot itself become a copy of the privileged material.

Retention

The default retention window is 90 days. Audit entries older than that are pruned on a rolling basis by the server process. Retention is configurable via the FIRM_BOT_AUDIT_RETENTION_DAYS environment variable; set it to 0 to disable audit logging entirely.

No analytics, no telemetry, no third-party scripts

The firm-bot source contains no analytics SDKs and no telemetry calls. This website loads exactly one external resource beyond its own static assets: the Inter and JetBrains Mono web fonts from Google Fonts. Font requests are anonymous at the protocol level (no cookies are set for plain font CSS), and the request carries only the user agent and referrer that any HTTP request inherently transmits. No analytics scripts, ad networks, or session trackers are loaded on this site or in the firm-bot binary.
