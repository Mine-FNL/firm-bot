The RAG chatbot that doesn't touch the cloud.

firm-bot is a citation-required, local-first RAG builder for legal, audit, and consultancy firms that can't send privileged material to someone else's vector store. MIT-licensed. No vendor on the chain of custody.

Built for compliance reviews

Every design choice answers the question your SOC 2 auditor or vendor-risk team will ask.

📜

Citation-required

Every claim anchored to [file:page]. An LLM-as-judge flags ungrounded answers. No silent fabrication.

🔌

Local-first

No cloud calls during operation. Ollama + sentence-transformers + Chroma all run on your hardware. Network egress = zero.

🧱

Structure-aware chunker

Recognises Article §, Section, Title Case, ALL CAPS, WHEREAS preambles. Sections stay intact under the merge step.

🛡️

STRIDE threat model

Published in SECURITY.md. Per-IP rate limit, body cap, CORS allow-list, audit log — every control documented.

📒

Query audit log

Append-only JSONL per firm with retention. Never logs the question or answer text — only their SHA-256 hashes. SIEM-friendly.

🔑

Optional API key auth

Opt-in shared-secret gate. Bearer / X-API-Key headers. Exempts /healthz + /metrics + UI for monitoring.
